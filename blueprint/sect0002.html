1 Representations of Lie algebras

This chapter is pure algebra with no physics content whatsoever: it fixes what a representation of a Lie algebra even is, and proves the single structural fact — Schur’s lemma — that everything downstream leans on repeatedly. Physically-minded readers can think of a representation as “a symmetry acting on a space of quantum states,” and of Schur’s lemma as the formal version of the physicist’s heuristic that an operator commuting with every symmetry of an irreducible system must be a scalar (this is exactly how the Casimir element in Chapter 3 is eventually shown to act as a single number, the quantum number that labels an irreducible multiplet).

1.1 The representation object

Mathlib’s primitive notion of a representation is not a bundled morphism but a pair of type classes making a type \(M\) into a Lie module for \(L\). The explicit homomorphism is extracted from this structure, not the other way around: there is currently no public constructor turning an arbitrary Lie algebra morphism \(L \to \operatorname {End}_K(M)\) back into these instances. Consequently this project keeps two layers: a generic layer stated directly in terms of LieRingModule/LieModule (used from §2.1 onward), and an explicit-morphism layer used for the physics representations in the later chapters, connected by a bridge construction.

Definition 1 Lie module structure
✓
#

Lean declarations

  • LieRingModule
  • LieModule

A Lie module of \(L\) on a \(K\)-vector space \(M\) is given by a bracket action \(L \times M \to M\), \((x, m) \mapsto \mathfrak {x}\cdot m\), that is \(K\)-bilinear and satisfies the Leibniz identity \(\mathfrak {[x,y]}\cdot m = x \cdot (y \cdot m) - y \cdot (x \cdot m)\).

Definition 2 Representation homomorphism
✓
#

Uses

  • Definition 1

  • LieModule.toEnd

Every Lie module structure on \(M\) yields a Lie algebra homomorphism \(\rho \colon L \to \operatorname {End}_K(M)\) with \(\rho (x)(m) = \mathfrak {x}\cdot m\), and conversely the bracket action is recovered by evaluating \(\rho \).

1.2 Generic representations as Mathlib objects

Mathlib does not just have the typeclass pair of Definition 1: it has a full bundled API around it — submodules, module homomorphisms, and irreducibility — that supersedes what a naive first pass would build from scratch. Anything stated for a type \(M\) that already carries \(\texttt{LieRingModule}\)/\(\texttt{LieModule}\) instances (as is the case throughout Chapters 2–3, where the acting object is always an actual Lie algebra with an actual Mathlib representation) should use these objects, not ad hoc predicates.

Definition 4 Lie module homomorphism
✓

A LieModuleHom \(M \to _{\! L} N\) (notation \(M \xrightarrow {R,L} N\)) bundles a \(K\)-linear map together with a proof that it commutes with the bracket action; it carries an identity, composition, and (since it extends a linear map into an \(R\)-module of maps) an \(R\)-module structure, so sums, differences, and scalar multiples of homomorphisms between the same pair of modules are again homomorphisms with no separate lemma required.

Definition 7 Explicit representation
✓
#

An explicit representation of \(L\) on \(V\) is a Lie algebra homomorphism \(\rho \colon L \to \operatorname {End}_K(V)\). This is only needed for the physics layer (Chapters 4–5), where the same underlying type must carry several differently-sourced actions (e.g. two named \(\mathfrak {sl}_2\)-triples on one bound state space) without polluting the global instance cache with competing LieModule instances. It packages the same data as Definition 2, presented explicitly instead of via typeclass search.

Definition 8 Invariant subspace, intertwiner (explicit form)
✓

  • QuantumRepresentationTheory.IsInvariantSubspace

For an explicit representation \(\rho \) (Definition 7), a subspace \(W \le V\) is invariant if \(\rho (x)(W)\subseteq W\) for all \(x \in L\), and a linear map \(f\colon V\to W\) intertwines \(\rho _V,\rho _W\) if \(f\circ \rho _V(x) = \rho _W(x)\circ f\) for all \(x\). These are the explicit-form counterparts of Definitions 3, 4, needed only because \(\rho \) does not come with ambient typeclass instances.

Remark 13 Missing bridge: from a morphism to a module instance

A genuinely missing piece of Mathlib API is a construction turning an explicit \(\rho \colon L \to \operatorname {End}_K(V)\) (Definition 7) into local LieRingModule/LieModule instances on \(V\) (Definition 1), so that the generic machinery of §1.2–§3.2 can be applied to the explicit physics representations of Chapters 4–5. This should be phrased either as a local instance-producing definition or as a LieModule.toEnd-compatible wrapper type.

1.3 Schur’s lemma

We take the direct eigenvalue route to Schur’s lemma rather than routing through the universal enveloping algebra: it is shorter, and it isolates exactly the facts needed later (§3.2) to show the Casimir element acts by a scalar. It is stated generically (Definitions 4, 6), which is the form Chapters 2–3 actually need.

Theorem 14 Existence of an eigenvalue
✓
#

Lean declarations

  • Module.End.exists_eigenvalue

If \(K\) is algebraically closed, \(V\) is finite-dimensional and nonzero, and \(f \in \operatorname {End}_K(V)\), then \(f\) has an eigenvalue.

Theorem 15 Eigenspace of an endomorphism is nonzero

Under the hypotheses of Theorem 14, there is \(c \in K\) with \(\ker (f - c \cdot \mathrm{id}_V) \neq 0\).

Theorem 16 Schur’s lemma
#

Uses

  • Definition 4
  • Definition 6
  • Theorem 5
  • Theorem 15

Lean declarations

  • QuantumRepresentationTheory.schur

Let \(K\) be algebraically closed, let \(M\) be a finite-dimensional irreducible Lie module for \(L\) (Definition 6), and let \(f \colon M \to _{\! L} M\) be a LieModuleHom (Definition 4). Then \(f = c \cdot \mathrm{id}_M\) for some \(c \in K\): apply Theorem 15 to the underlying endomorphism to get \(c\) with \(\ker (f - c\cdot \mathrm{id}) \neq 0\); since \(f - c\cdot \mathrm{id}\) is again a LieModuleHom, its kernel is a Lie submodule (Theorem 5), hence all of \(M\) by irreducibility.
