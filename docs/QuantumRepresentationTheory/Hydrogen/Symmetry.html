                    theorem QuantumRepresentationTheory.BoundStateRepresentation.equal_casimirs {V : Type u_1} [AddCommGroup V] [Module ℂ V] (H : BoundStateRepresentation V) (hIsqKsq : H.Ix * H.Ix + H.Iy * H.Iy + H.Iz * H.Iz = H.Kx * H.Kx + H.Ky * H.Ky + H.Kz * H.Kz) {n₁ n₂ : ℕ} (hI : H.Ix * H.Ix + H.Iy * H.Iy + H.Iz * H.Iz = (↑n₁ / 2 * (↑n₁ / 2 + 1)) • 1) (hK : H.Kx * H.Kx + H.Ky * H.Ky + H.Kz * H.Kz = (↑n₂ / 2 * (↑n₂ / 2 + 1)) • 1) :
                    n₁ = n₂

                    Equality of the two Casimir eigenvalues (thm:hyd-equal-casimirs). On any irreducible summand of V under the joint (I,K) action, the Casimir eigenvalues of the I-triple and K-triple coincide, forcing equal spin labels n₁ = n₂ (where I² acts as (n₁/2)(n₁/2+1) and K² as (n₂/2)(n₂/2+1), per AngularMomentumRepresentation.Jsq_eq_smul). The hypothesis hIsqKsq packages the Hamiltonian-level identity I² = K² that, in a full (non-decoupled) treatment, would be derived from the explicit form of the hydrogen Hamiltonian (cf. Physlib's lrlOperatorSqr_eq); here it is taken as given, consistent with this project's decoupled algebraic scope.
