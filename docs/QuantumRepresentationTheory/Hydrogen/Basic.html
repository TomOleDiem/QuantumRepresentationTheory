    Hydrogen/Basic #

    Part of the blueprint for algebraic quantum representation theory. See blueprint/src/content.tex, §"The Runge–Lenz vector" (sec:hyd-basic). As decided for the scope of this project, this is a purely algebraic model: BoundStateRepresentation packages a finite-dimensional negative-energy eigenspace as given data, rather than deriving it from Physlib's Hilbert-space Hamiltonian (Physlib.QuantumMechanics.Hydrogen.Basic).

        structure QuantumRepresentationTheory.BoundStateRepresentation (V : Type u_2) [AddCommGroup V] [Module ℂ V] extends QuantumRepresentationTheory.AngularMomentumRepresentation V :
        Type u_2

        Bound-state representation (def:hyd-bound-state). The explicit representation of the hydrogen Hamiltonian's dynamical symmetry algebra on a fixed negative-energy eigenspace V: the angular momentum representation (Jx,Jy,Jz), the (unnormalized) Runge–Lenz operator (Mx,My,Mz), and the physical parameters (mass m, Coulomb constant k, energy eigenvalue E < 0).
