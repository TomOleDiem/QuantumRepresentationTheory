        Classification of irreducible $\sltwo$-modules (thm:sl2-classification). Every finite-dimensional irreducible module for an sl₂-triple, over an algebraically closed field of characteristic zero, is isomorphic (as a module for the generated subalgebra) to the standard module V(n) for a unique n.
