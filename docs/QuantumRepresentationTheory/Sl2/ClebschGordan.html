    Sl2/ClebschGordan #

    Part of the blueprint for algebraic quantum representation theory. See blueprint/src/content.tex, §"Clebsch–Gordan decomposition" (sec:sl2-cg).

    source
    theorem QuantumRepresentationTheory.clebsch_gordan_finrank (m n : ℕ) :
    (m + 1) * (n + 1) = ∑ k ∈ Finset.range (min m n + 1), (m + n - 2 * k + 1)

    Clebsch–Gordan decomposition, dimension form (thm:sl2-clebsch-gordan): the numerical shadow (m+1)(n+1) = ∑_{k=0}^{min(m,n)} (m+n-2k+1) of the module isomorphism V(m) ⊗ V(n) ≅ ⊕_k V(m+n-2k).

    theorem QuantumRepresentationTheory.clebsch_gordan {K : Type u_1} [Field K] (m n : ℕ) :
    Nonempty (TensorProduct K (StandardSl2Module K m) (StandardSl2Module K n) ≃ₗ[K] DirectSum (Fin (min m n + 1)) fun (_k : Fin (min m n + 1)) => StandardSl2Module K (m + n - 2 * ↑_k))

    Clebsch–Gordan decomposition, vector-space form (thm:sl2-clebsch-gordan): V(m) ⊗ V(n) is linearly isomorphic to ⊕_{k=0}^{min(m,n)} V(m+n-2k).
