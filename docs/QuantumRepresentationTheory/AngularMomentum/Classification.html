      theorem QuantumRepresentationTheory.AngularMomentumRepresentation.spin_classification {V : Type u_1} [AddCommGroup V] [Module ℂ V] [FiniteDimensional ℂ V] (ρ : AngularMomentumRepresentation V) (hirr : ρ.IsIrreducible) :
      ∃ (n : ℕ), Nonempty (V ≃ₗ⁅ℂ,↥(IsSl2Triple.toLieSubalgebra ℂ ⋯)⁆ StandardSl2Module ℂ n)

      Spin classification (thm:am-spin-classification): every finite-dimensional irreducible angular momentum representation is isomorphic (as a module for the sl₂-subalgebra generated by (2Jz,J+,J-)) to the standard module V(n), for a unique n : ℕ; the physical spin is j = n/2, of multiplicity (dimension) n + 1 = 2j + 1.

      theorem QuantumRepresentationTheory.AngularMomentumRepresentation.Jsq_eq_smul {V : Type u_1} [AddCommGroup V] [Module ℂ V] [FiniteDimensional ℂ V] (ρ : AngularMomentumRepresentation V) (hirr : ρ.IsIrreducible) :
      ∃ (n : ℕ), ρ.Jx * ρ.Jx + ρ.Jy * ρ.Jy + ρ.Jz * ρ.Jz = (↑n / 2 * (↑n / 2 + 1)) • 1

      J² = Jx²+Jy²+Jz² is (a rescaling of) the Casimir element (thm:am-j2-casimir): on an irreducible summand of spin j = n/2, J² acts as the scalar j(j+1).
